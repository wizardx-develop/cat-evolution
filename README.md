# 🐱 Кото-Эволюция

Небольшой idle / clicker / merge на чистом HTML5 + Canvas + Vanilla JS.
Без сборщиков, без зависимостей, без единого mp3 — звук синтезируется Web Audio API.

## Механики

- **Клик** по большому котику → монеты, шанс крита ×7.
- **Мерж**: перетащи двух одинаковых котов друг на друга → новый вид + монеты.
  Каждый новый вид навсегда даёт **+10% ко всему доходу**.
- **Генераторы** (10 шт.) — пассивный доход, цена растёт ×1.15 за уровень.
- **Улучшения**: «Сильные лапы» (+к клику) и «Лакомство» (+5% дохода).
- **Реклама за вознаграждение**: ×2 доход на 5 минут или моментальный подарок.
- **Сохранение** в localStorage + облако Яндекс Игр, офлайн-доход до 8 часов.
- **Коллекция** из 10 видов: 🐾 → 🐱 → 🐈 → 😼 → 🐈‍⬛ → 🐆 → 🦁 → 🐯 → 🐅 → 👑.

## Структура

```
index.html          — разметка, подключение /sdk.js и скриптов
style.css           — весь интерфейс (CSS-панели, кнопки, оверлеи)
js/config.js        — баланс, контент, форматирование чисел (чистый)
js/rules.js         — чистые правила: экономика, мерж, офлайн (тестируется в Node)
js/audio.js         — синтез звуков через Web Audio API
js/platform.js      — Яндекс Игры SDK, Telegram Mini Apps, демо-режим рекламы
js/render.js        — Canvas-рендер: кликер + сетка 6×4, частицы, летящие числа
js/game.js          — состояние, ввод, HUD, цикл кадра
test/rules.test.js  — юнит-тесты правил (node test/rules.test.js)
```

## Локальный запуск

Просто откройте `index.html` в браузере — двойным кликом, без сервера и без окон терминала.
Работает офлайн: SDK Яндекса не загрузится → включится демо-режим, а реклама
будет имитироваться полноэкранным оверлеем с обратным отсчётом.

Проверка правил без браузера:

```
node test/rules.test.js
```

## Публикация в Яндекс Игры

1. Соберите архив: `index.html`, `style.css`, `js/` — **index.html в корне архива**.
2. [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console/) → «Создать игру» → загрузить архив.
3. SDK подключается автоматически: в `index.html` уже стоит
   `<script async src="/sdk.js">` — так требует актуальная документация для загрузки через Консоль.
4. Монетизация: в Консоли включите ad-блоки, в игре уже вызывается
   `ysdk.adv.showRewardedVideo()` с наградой строго в `onRewarded`.
5. Проверка перед модерацией:
   - откройте игру с `?debug-mode=16` — индикатор лоадера должен показывать **IT**;
   - Game Ready индикатор должен позеленеть (вызывается `ysdk.features.LoadingAPI.ready()`
     после первого кадра игры).
6. Требования модерации уже учтены: реклама только по жесту пользователя,
   нет `setInterval`-показов, звук только после первого взаимодействия,
   нет внешних ссылок и чужих логотипов.

## Публикация на GitHub Pages (хостинг для Telegram / веб)

1. В корне репозитория лежит `index.html` — Pages отдаёт его как есть, без сборки.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / root**.
3. Ссылка будет `https://<user>.github.io/<repo>/` — её же вставляете в @BotFather
   при создании мини-приложения.

## Telegram Mini Apps

- В `platform.js` уже есть инициализация `Telegram.WebApp` (`ready()`, `expand()`,
  цвет шапки/фона, `disableVerticalSwipes`, подтверждение закрытия) — при
  встраивании в бота ничего менять не нужно.
- Скрипт `https://telegram.org/js/telegram-web-app.js` уже подключён в `index.html`.
- Запуск мини-приложения через @BotFather (2 минуты):
  1. Откройте @BotFather → `/newbot` → имя и логин (`..._bot`) → скопируйте токен
     (это секрет, храните у себя — понадобится для Stars/рекламы).
  2. После того как игра будет на HTTPS-хостинге: `/newapp` → выберите бота →
     название, описание, иконка → вставьте ссылку на игру → получите
     `t.me/<bot>/<appname>`.
  3. Проверка: откройте ссылку на телефоне — игра должна раскрыться на весь экран,
     кнопки рекламы сработают в демо-режиме (AdsGram подключается позже).
- **AdsGram (реклама)** уже подключён в `platform.js`: SDK `sad.adsgram.ai`
  грузится динамически **только внутри Telegram** и только если заполнен
  `CG.CONFIG.ADSGRAM_BLOCK_ID`. Как вставить свой ID:
  1. Зарегистрируйтесь на https://adsgram.ai (вход через Telegram).
  2. Создайте приложение → выберите бота → формат **Reward (Rewarded video)**.
  3. Скопируйте block ID и впишите его в `js/config.js` → `ADSGRAM_BLOCK_ID`.
  4. Вне Telegram и в Яндекс Играх останется демо-режим/SDK Яндекса — ничего
     лишнего не грузится. Отладка показа: добавьте к адресу `?ad-debug`.
- Награда выдаётся только при `.then()` (ролик досмотрен до конца);
  `.catch()` (ошибка/пропуск) показывает игроку «реклама временно недоступна».
- Продажа бустов за Telegram Stars требует бэкенда бота (`payments` + `invoice`);
  в игровой код это выносится отдельным покупным действием рядом с кнопками рекламы.
- **Бот, который присылает ссылку на игру** — папка `bot/` содержит готовый
  сервер (Vercel serverless, бесплатный) и локальный вариант (polling):
  1. Создай аккаунт на https://vercel.com, импортируй репозиторий (корень проекта
     — папка `bot/`).
  2. В настройках проекта → Environment Variables добавь:
     - `BOT_TOKEN` — токен бота из @BotFather
     - `GAME_URL` — ссылка на мини-приложение (по умолчанию GitHub Pages)
  3. Деплой. Скопируй URL вида `https://<name>.vercel.app/api/webhook`.
  4. Зарегистрируй вебхук (один раз, в браузере):
     `https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<name>.vercel.app/api/webhook`
  5. Теперь `/start` в боте присылает inline-кнопку «🎮 Играть», которая
     открывает мини-приложение.
- **Без хостинга (быстро)**: @BotFather → `/setmenubutton` → выбери бота →
  вставь ссылку `t.me/<бот>/<shortname>` → в чате появится кнопка меню,
  которая сразу открывает игру. Локальная проверка без сервера:
  `BOT_TOKEN=... node bot/polling.js` (работает пока запущен).
- **Где взять botid для AdsGram**: это username бота (без `@`), например
  `CatEvolutionGameBot`. Сначала создайте бота через @BotFather (`/newbot`),
  потом в AdsGram выберите его из списка — botid подставится автоматически.

## Дальнейшие шаги (конвейер 5–10 игр)

Каркас переиспользуем целиком: `config.js` (контент) + `rules.js` (экономика) +
`platform.js` (SDK) + `render.js` (поле) — новая игра это в основном новые данные
и рендер. Следующие кандидаты: 2048-кликер, викторина, idle-ферерма, мерж-оружие.
